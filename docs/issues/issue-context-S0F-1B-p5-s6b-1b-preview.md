## Context

- The issue S6B-1B builds upon the previously established evidence families and retention baselines from S6B-1A to address naming clarity.
- It targets three main naming categories: retained-summary files in artifacts/, tmp-scratch outputs under _tmp_ and _local_ directories, and snapshot run identity in docs/labs/_snapshot/**.
- The naming conventions are designed to enable operators to identify file family, ownership, purpose, and status (retained or temporary) without opening file contents.
- This version also maintains a sample set of current-to-target rename mappings to facilitate practical cleanup and standardization later on.
