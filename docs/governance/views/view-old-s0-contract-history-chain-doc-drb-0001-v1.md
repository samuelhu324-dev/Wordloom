# Old S0 Contract History Chain: DOC-DRB-0001 v1

## Purpose

- This view is the first bounded current-surface-first history-chain surface for old-`S0` absorption into `DOC`.
- It exists so readers can start from `DOC-DRB-0001` and trace backward through the direct source-owner, promotion, consolidation, and strongest prerequisite chain without replaying the whole old-`S0` set manually.
- It is not a second current contract body, not a replacement for `view-doc-history-and-lineage-v1.md`, and not a full chronology replay of every predecessor log.
