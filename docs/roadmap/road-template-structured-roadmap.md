## Purpose

- This file remains as a compatibility entry because older logs and roadmap notes already reference `road-template-structured-roadmap.md`.
- New roadmap work should choose one of the split templates below instead of treating this file as the canonical authoring template.

## Template chooser

- Use `docs/roadmap/road-template-main-roadmap.md` for a mainline roadmap such as `road-001`.
- Use `docs/roadmap/road-template-branch-roadmap.md` for a focused branch roadmap such as `road-001-01`.

## Split rationale

- Mainline roads own the long-running backbone, milestone language, and absorbed child-log outcomes.
- Branch roads appear when a focused detour is needed and should contribute back to the parent without polluting the mainline body.
- Both road types still use the same child-log-first bridge principle introduced in `S0E-3A`.

## Child-log-first rule

- Mainline and branch roadmaps should both use child-log-first bridge ledgers.
- If a branch road contributes to a parent road, both files should record the same child-log mapping explicitly.
